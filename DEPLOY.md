# 🚀 Инструкция по деплою на GitHub Pages

## Быстрый старт (5 минут)

### 1. Создайте аккаунт на GitHub
Если у вас ещё нет аккаунта, зарегистрируйтесь на [github.com](https://github.com)

### 2. Создайте новый репозиторий
1. Нажмите на кнопку **"New"** (зелёная кнопка) или перейдите по ссылке [github.com/new](https://github.com/new)
2. Заполните поля:
   - **Repository name**: `study-timer`
   - **Description**: `Учебный таймер для управления временем`
   - **Public** (обязательно!)
   - ❌ НЕ ставьте галочку "Add a README file"
3. Нажмите **"Create repository"**

### 3. Загрузите проект на GitHub

Откройте терминал (командную строку) в папке проекта и выполните команды:

```bash
# Инициализация Git
git init

# Добавление всех файлов
git add .

# Первый коммит
git commit -m "Initial commit: Учебный таймер"

# Подключение к вашему репозиторию
# ЗАМЕНИТЕ "ВАШ_ЛОГИН" на ваш логин GitHub!
git remote add origin https://github.com/ВАШ_ЛОГИН/study-timer.git

# Переименование ветки в main
git branch -M main

# Отправка кода на GitHub
git push -u origin main
```

### 4. Дождитесь автоматического деплоя

После отправки кода GitHub Actions автоматически:
1. Соберёт проект (2-3 минуты)
2. Развернёт его на GitHub Pages

**Проверить статус деплоя:**
- Перейдите в репозиторий
- Нажмите на вкладку **"Actions"**
- Вы увидите процесс сборки

### 5. Включите GitHub Pages

1. В репозитории перейдите в **"Settings"** (настройки)
2. В левом меню найдите раздел **"Pages"**
3. В разделе **"Source"** выберите **"GitHub Actions"**
4. Сохраните настройки

### 6. Получите ссылку на приложение

Через 1-2 минуты ваше приложение будет доступно по адресу:

```
https://ВАШ_ЛОГИН.github.io/study-timer/
```

**Пример:**
Если ваш логин `ivan123`, то ссылка будет:
```
https://ivan123.github.io/study-timer/
```

## 📱 Установка на смартфон

После того как приложение развернуто, вы можете установить его на смартфон:

### Android (Chrome)
1. Откройте ссылку в браузере Chrome
2. Нажмите на меню (⋮ три точки в правом верхнем углу)
3. Выберите **"Установить приложение"** или **"Добавить на главный экран"**
4. Подтвердите установку

### iOS (Safari)
1. Откройте ссылку в браузере Safari
2. Нажмите кнопку **"Поделиться"** (квадрат со стрелкой вверх внизу экрана)
3. Прокрутите вниз и выберите **"На экран «Домой»"**
4. Нажмите **"Добавить"**

## 🔄 Обновление приложения

Когда вы внесёте изменения в код:

```bash
# Добавьте изменения
git add .

# Сделайте коммит
git commit -m "Описание изменений"

# Отправьте на GitHub
git push
```

GitHub Actions автоматически пересоберёт и развернёт обновлённую версию.

## ❓ Решение проблем

### Проблема: Страница не открывается (404)
**Решение:** Подождите 2-3 минуты после первого push. GitHub Pages нужен время для первого деплоя.

### Проблема: Белый экран или ошибки
**Решение:** Проверьте консоль браузера (F12) и вкладку Actions в репозитории на наличие ошибок сборки.

### Проблема: Ссылка не работает
**Решение:** Убедитесь, что:
- Репозиторий публичный (Public)
- В Settings → Pages выбран источник "GitHub Actions"
- Workflow успешно завершился (зелёная галочка в Actions)

### Проблема: Изменения не применяются
**Решение:** Очистите кэш браузера (Ctrl+Shift+R или Cmd+Shift+R)

## 🎯 Альтернативные платформы

Если GitHub Pages не подходит, можно использовать:

### Netlify (самый простой)
1. Перейдите на [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите папку `dist/` в браузер
3. Готово! Получите ссылку

### Vercel
1. Зарегистрируйтесь на [vercel.com](https://vercel.com)
2. Импортируйте репозиторий с GitHub
3. Нажмите "Deploy"
4. Получите ссылку
