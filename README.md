# Учебный Таймер 📚

Веб-приложение для управления временем выполнения уроков с функцией PWA (Progressive Web App).

## Возможности

- ✅ Добавление уроков с выбором предмета и длительности
- ✅ Круговой анимированный таймер
- ✅ Автоматические перерывы между уроками
- ✅ Управление процессом (старт/пауза/сброс)
- ✅ Детальная статистика выполнения
- ✅ Звуковые уведомления
- ✅ Эффект конфетти при завершении всех задач
- ✅ Адаптивный дизайн для мобильных устройств
- ✅ PWA - можно установить на смартфон

## Установка на смартфон

### Android (Chrome)
1. Откройте приложение в браузере Chrome
2. Нажмите на меню (три точки)
3. Выберите "Установить приложение" или "Добавить на главный экран"
4. Подтвердите установку

### iOS (Safari)
1. Откройте приложение в браузере Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Выберите "На экран «Домой»"
4. Нажмите "Добавить"

## Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## Деплой на GitHub Pages

### Шаг 1: Создайте репозиторий на GitHub
1. Зайдите на [github.com](https://github.com)
2. Создайте новый репозиторий с именем `study-timer`

### Шаг 2: Загрузите проект в репозиторий

```bash
# Инициализация Git
git init

# Добавление файлов
git add .

# Первый коммит
git commit -m "Initial commit"

# Подключение удалённого репозитория
git remote add origin https://github.com/ВАШ_ЛОГИН/study-timer.git

# Отправка кода на GitHub
git branch -M main
git push -u origin main
```

### Шаг 3: Автоматический деплой
Файл `.github/workflows/deploy.yml` уже настроен для автоматического деплоя. После каждого push в ветку `main` приложение будет автоматически собираться и развёртываться на GitHub Pages.

### Шаг 4: Включите GitHub Pages
1. Зайдите в настройки репозитория → **Settings**
2. Раздел **Pages** (в левом меню)
3. В **Source** выберите **GitHub Actions**
4. Workflow автоматически запустится

### Шаг 5: Получите ссылку
Через 1-2 минуты приложение будет доступно по адресу:
```
https://ВАШ_ЛОГИН.github.io/study-timer/
```
